# O Urso

Projeto web com frontend em HTML e backend em Node.js com Express.

## Estrutura

- `public/HomePage.html` — Frontend (página visível no browser)
- `server.js` — Backend (servidor que serve a página e a API)
- `package.json` — Configuração do projeto

## Como correr

```
npm install
node server.js
```

Abrir no browser: http://localhost:3000/HomePage.html
